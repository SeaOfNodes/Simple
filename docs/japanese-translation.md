# Japanese translation / 翻訳の保守方針

English is authoritative. The contributed Japanese translation is maintained on
a best-effort basis; English edits and chapter reorganizations never wait for
translation updates. Move Japanese files and update navigation when renumbering
chapters; prose updates can follow separately. Contributions are welcome, without
an ongoing maintenance obligation for the original translator.

[英語版](../README.md)が正式な文書です。この日本語訳は寄贈されたもので、可能な範囲で保守されますが、
英語版より更新が遅れることがあります。英語版の編集や章の再構成を、翻訳の更新待ちにすることはありません。
章を移動・改番する際は、日本語ファイルも一緒に移動して章の見出しやリンクを更新し、本文の翻訳は後から更新できます。
翻訳の改善は歓迎しますが、元の寄贈者に継続的な保守を義務付けるものではありません。
